# Phase 4 — 실측 비교와 공유

상태: 완료.

- 실제 driver가 생성하는 workflow v4 및 기존 paired v2 importer를 유지했다. 문서의 이전 형식 안내를 실제 지원 버전에 맞췄다.
- workflow의 반복별 초기 준비·전환·추가 감사·검증 시간을 보존한다. 워밍업, 범위 불일치, 실패·제외 사유와 음수 표본을 제거하지 않는다.
- 같은 샤드의 명령 구간, 원래 parent suite와 Click의 요청 구간을 각각 표시한다. fixture의 음수 결과를 현재 작업이 느려졌다는 주장으로 연결하지 않는다.
- 각 경로 중앙값과 쌍별 차이의 중앙값을 구분한다. 비교 제거 기능과 상세 비용 표를 추가했다.
- 요약 복사, JSON v4, 독립 HTML이 같은 presentation을 사용한다. HTML에도 실제 대응 블록과 시간 막대를 포함하며 외부 자산을 요구하지 않는다.
- 실패·미완료 요약은 상태를 먼저 표시한다. 과거 공유본에는 현재 작업의 controls/task/shadow 정보를 연결하지 않는다. 묶음명은 allowlist를 통과시키고 사용자 문자열은 textContent로 렌더링한다.

검증: DOM 테스트에서 동일 수치·단위·상태, median 반례, 잘못된 JSON, 악성 HTML·경로 라벨, 과거 공유 범위를 확인했다. 실제 workflow driver의 32개 쌍 표본을 importer에 전달하는 테스트를 포함해 benchmark 관련 11개가 통과했다.

브라우저에서 실제 v4 파일을 가져오고 21개 유효 비교 그룹과 음수 fixture 안내·비용 상세 표시를 확인했다. 요약 복사와 HTML 내보내기 동작의 완료 상태를 확인했다. in-app browser의 다운로드 이벤트가 반환되지 않아 내려받은 HTML 파일을 다시 열어 검수하지는 못했다. HTML 내용 일치와 외부 script/asset 부재는 export 테스트로 확인했다.
