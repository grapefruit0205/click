# Dashboard impact — 공통 규칙

사용자가 제공한 프롬프트와 CoachPro 참고 이미지를 Click 0.90.0의 기존 대시보드에 적용한다. 사용자의 후속 요청은 대시보드 구현까지다. 첨부 문서의 단계별 중단 문장은 작업 재개를 위한 원문이며, 이번 작업은 관련 구현·검증·기록을 이어서 수행한다.

- 기존 집계·projection·HTML/JSON 내보내기 경로를 개선한다. 새 프레임워크, 외부 자산, 서비스, 분석 SDK를 도입하지 않는다.
- 대시보드는 읽기 전용이다. 승인·재사용 권한·runner·검사 선택 정책을 변경하지 않는다.
- canonical plan과 실제 실행 결과만 사용한다. Shadow·재사용 예정·미실행은 재사용 실적이 아니다.
- 검증 묶음, 테스트 케이스, 실행 구간 합계, 전체 요청 대기시간을 구분한다.
- 추정·부분 추정·미측정·관찰된 0을 구분한다. 추정 표시는 숫자 바로 옆에 둔다. 부분 표본 합계에 최소·≥를 붙이지 않는다.
- 실패·취소·미확정은 상태를 유지한다. 새 작업에 이전 작업의 성공을 자동 대입하지 않는다.
- 비교·공유·새로고침은 테스트를 실행하지 않는다. 시간·횟수를 토큰이나 요금으로 환산하지 않는다.
- 공유본은 허용된 필드만 포함하고 사용자 문자열을 HTML로 실행하지 않는다.
- 사용자 변경과 다른 작업 폴더를 보존한다. commit/push·설치본 교체·게시를 자동 수행하지 않는다.
- 각 단계에서 관련 검증을 수행하고 결과를 기록한다. 변경 없는 전체 검증을 반복하지 않는다. 미실행을 통과로 표시하지 않는다.
- 이미지의 민트/청록, 반투명 카드, 여백, 왼쪽 탐색 구조를 참고한다. 축구 콘텐츠와 예시 수치는 운영 화면에 넣지 않는다.
