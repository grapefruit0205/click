# Phase 2 — 첫 화면과 반응형 표현

상태: 완료.

- 기존 HTML/CSS/JS를 개선했다. 민트·청록색 배경, 반투명 카드, 사이드바를 적용하고 데스크톱에서 대표값과 전후 비교를 나란히 배치했다.
- 시간 근거가 충분하면 회피 실행시간과 바로 옆의 추정 표시를 강조한다. 시간 근거가 부족하면 재사용 묶음 수를 대표값으로 보여준다.
- 요청 묶음별 대응 블록과 실제 상태 표시를 추가했다. 시간 막대는 같은 0축을 사용하며 E와 회피 추정 A를 구분한다. 실제 0 길이를 유지하고 수치는 막대 밖에서도 읽힌다.
- 첫 실행·전부 실행·전부 재사용·진행·실패·취소·거부를 분리했다. 정상 완료에만 N/N 결과 확보를 표시한다.
- 모바일에서 사이드바의 최소 너비 때문에 생긴 넘침을 수정했다. 한국어 단어 줄바꿈, 가로 탐색, reduced-motion 스타일을 적용했다.

검증: 관련 DOM/산식 테스트 통과. Chromium의 1440×900와 390×844 화면을 실제 확인하고 [캡처](../screenshots/desktop.jpg)를 보관했다. 모바일 정상·미측정·실패 상태를 별도로 캡처했다. 390px 화면의 내용 잘림과 가로 넘침이 없음을 확인했다.

키보드 Enter로 실행 묶음 필터를 조작했다. reduced-motion 규칙이 브라우저 CSSOM에 존재하며 애니메이션·전환을 끄는 것은 확인했으나 OS의 접근성 설정 자체를 전환한 검증은 수행하지 않았다.

화면의 12/3/9와 90초는 합성 렌더링 fixture에만 존재한다. 실제 실행 연결 검증은 Phase 5에 별도로 기록했다.
