# Phase 3 — 묶음별 이유와 이력

상태: 완료.

- Hero의 링크와 재사용 수를 선택하면 재사용 필터가 적용된 묶음 목록으로 이동한다. 대응 블록을 선택하면 해당 묶음의 상세 근거가 열린다.
- 전체·재사용·실행 필터와 실제 source 상태를 연결했다. 기존 canonical reason code, 원본 실행 시각·출처·시간 표본을 유지한다.
- 최근 관찰된 배치를 작업 흐름으로 표시하고 과거 선택임을 배치·시점으로 명시한다. 관찰하지 않은 변경 파일이나 의도는 만들지 않는다.
- 현재 작업에 배치가 없으면 이전 작업의 성과를 현재 값으로 대입하지 않는다. 과거 배치는 명시적으로 선택해야 하며 현재 작업의 승인 상세는 숨긴다.
- polling은 명시적으로 선택한 과거 배치와 필터·초점을 유지한다. 중첩 refresh를 막았다. 완료 이력 누적에는 시간대, 보관 범위와 누락 표본을 함께 표시한다.

검증: 산식·projection·DOM 테스트에서 중복/재시도/부분 시간/새 작업/과거 export 범위 분리를 확인했다. 브라우저에서 Hero→재사용 9개, 실행 필터→3개, 새 작업의 빈 현재 값, 과거 배치 선택과 새로고침 후 선택 유지 및 누적치 불변을 확인했다.

변경: `hooks/click_shadow_dashboard.py`, 누적 집계/projection, 관련 테스트. 조회·필터·공유는 실행 권한을 생성하지 않는다.
