## Field contract

This classification covers all 47 fields in the current `_fresh_source` initializer, plus optional `shard` and dynamically written `last_success_duration_baseline`. Categories distinguish semantics from copying: a fact that binds the current lifecycle is rebuilt from validated current arguments rather than blindly copied.

| Category | Exact fields | Treatment and reason |
| --- | --- | --- |
| Prior verification facts | `verified_root`, `verified_at` | Explicitly copy the previously matched workspace root and original execution time. These do not grant execution permission. |
| Prior dependency facts | `verified_dependency_provider`, `verified_dependency_manifest_digest`, `verified_dependency_entry_digest`, `verified_dependency_digest`, `verified_dependency_paths`, `verified_dependency_observation_digest`, `verified_dependency_observation` | Explicitly copy the complete receipt inputs needed by the existing dependency owner/matcher, including complete observation payload and digest. Provider and relevant entry bind the selected dependency policy; input/observation facts support requalification. The manifest digest retains receipt schema and manifest origin integrity. Whole-manifest equality is deliberately not the reuse criterion: unrelated manifest entries may change while the selected entry remains valid. |
| Prior safe-change facts | `verified_safe_change_receipt` | Explicitly copy the complete precommitted baseline receipt; current policy, changed paths, check and Phase 2 decision context must still pass the existing matcher. A historical receipt alone is not current authorization. |
| Current identity/declaration | `kind`, `dependency_patterns`, `dependency_declaration_digest`, optional `shard` | Initialize from the validated current source and preserve its normalized declaration/shard; do not replace them with prior values. Requalification is restricted to matching `argv` sources. |
| Current lifecycle/completion | `status`, `verified_revision`, `last_exit_code` | Set only after successful requalification: passed/current revision for exact tree; stale/prior revision for dependency or safe-change reevaluation; exit zero reflects the validated prior PASS fact. Failure does not install a candidate. |
| Current attempts/retry | `attempts`, `unchanged_failure_retries` | Normal initializer defaults, both zero. No previous execution attempt or retry state transfers. |
| Current check/reservation | `last_check_digest`, `locked_check_digest`, `reserved_units`, `reserved_check_digest` | Set from the current validated requested check and units in the existing preparation path. Prior reservations are not copied. |
| Current successful-result binding | `verified_contract_digest`, `verified_check_digest`, `verified_units`, `verified_tree_digest`, `verified_environment_digest`, `verified_executable_digest`, `verified_host_coverage` | Set from validated current arguments. Current contract/check/units/environment/executable/coverage are bound anew; exact tree uses the current tree, while a non-exact candidate retains the prior tree until its existing receipt matcher approves promotion. No previous approval or claim becomes a current approval. |
| Measurement metadata | `last_success_duration_ms`, dynamic `last_success_duration_baseline` | Explicitly copy the original successful duration and its original sample/check/source/environment/observer provenance. Existing timing validators decide usability. These values do not authorize reuse and are not new execution samples; preserving them is required by existing shard timing/provenance behavior. |
| Dependency reuse audit | `dependency_reuse_count`, `last_dependency_reused_at`, `last_dependency_reused_from_revision` | Normal initializer defaults. Current successful promotion creates new audit values. |
| Safe-change reuse audit | `safe_change_reuse_count`, `last_safe_change_reused_at`, `last_safe_change_reused_from_revision`, `last_safe_change_paths`, `last_safe_change_path_count`, `last_safe_change_decision_digest` | Normal initializer defaults. The current decision supplies current audit metadata after matching. |
| Successor reuse audit | `successor_reuse_count`, `last_successor_reused_at`, `last_successor_origin_batch_id`, `last_successor_origin_evidence_session_id`, `last_successor_origin_contract_id`, `last_successor_candidate_digest`, `last_successor_origin_revision`, `last_successor_mode` | Normal initializer defaults, then current candidate provenance is recorded by `mark_successor_reuse`. Original `verified_at` remains unchanged. |
| Future/unknown fields | Any source key absent from the lists above | Excluded by default. Neither a `verified_` prefix nor a prior source value authorizes transfer. Whole contract, approval and runner claim state are not part of this source-copy contract. |

## Limits and handoff

It does not make workspace reads atomic. Full regression, generated source/distribution parity and automatic-sharding init/status/refresh acceptance remain for Phase 6; the targeted partial-shard successor regression passed here. Native Windows/macOS execution was not available in this Linux phase.
